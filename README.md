1) Project Title / Headline:-
Amazon Clone Website Using HTML & CSS

2) Short Description / Purpose:-
This project is a front-end clone of the Amazon
 homepage created using HTML and CSS.
The purpose of this project is to practice web development skills by designing a responsive e-commerce interface similar to Amazon, including a navigation bar, search section, hero banner, and product category cards.

3) Tech Stack:-
HTML5 – Structure of the website
CSS3 – Styling and layout design
Font Awesome – Icons for navbar and cart

4) Data Source:-
Sample product/category images downloaded from the internet
Inspiration taken from the official Amazon India Website
Custom static content used for educational purposes

5) Features / Highlights:-
Amazon-style responsive navigation bar
Search bar with category dropdown
Hero banner section with promotional sale image
Product category cards with images
Hover effects on navbar and cards
Shopping cart icon section
Clean UI design similar to Amazon homepage
Beginner-friendly front-end project for practice
